# קורפוס ספרותי עברי — גרסה 2.0.0

**לצפייה בממשק:** https://adichouni.github.io/BenYehuda-literary-corpus/

שירים וסיפורים קצרים מ[פרויקט בן-יהודה](https://benyehuda.org), לפי עשור הלידה של
המחבר (1880 ואילך). כל עשור מכיל **סטים שבכל אחד מהם כל מחבר מופיע פעם אחת**, עד 50
מחברים לסט. לכל ז'אנר ועשור יש חמישה סטים. כשלמחבר יש מספיק יצירות, בכל סט מופיעה
יצירה אחרת שלו. סט 0 הוא הסט הראשי.

| | מחברים לסט, לפי עשור לידה (1880 ... 1970+) |
|---|---|
| שירה | 24, 30, 29, 34, 50, 45, 47, 41, 32, 39 |
| פרוזה | 29, 24, 24, 14, 38, 24, 19, 23, 32, 50 |

**שנות הלידה** לקוחות מרשומת המחבר בבן-יהודה עצמו, לפי מזהה המחבר. בשני מקרים בלבד
הושלמה שנה מוויקינתונים, אחרי בדיקה ידנית. בגרסאות 1.x השנה נקבעה לפי התאמת שם, ו-106
יצירות שובצו בעשור שגוי. בממשק, יצירה שהעשור שלה תוקן מסומנת "עשור תוקן".

**טקסטים וזכויות:** הטקסט המלא מופיע כאן רק ליצירות שבנחלת הכלל (422 מתוך 2,028 בכל
הסטים). רוב היצירות מופיעות בבן-יהודה ברשות בעלי הזכויות. עבורן מופיעים כאן רק פרטי
היצירה וקישור לקריאה בבן-יהודה. הקורפוס המלא, לשימוש מחקרי, נשמר אצל צוות המחקר.

| קובץ / תיקייה | מה יש בו |
|---|---|
| `sets.csv` | שורה לכל יצירה בכל סט: סט, ז'אנר, עשור, מחבר, שנת לידה, קישור |
| `selection.csv` | שורה לכל יצירה שנמצאת בסט כלשהו, עם הסטים שלה ודגלי הניקוי. `in_core` מסמן את סט 0 |
| `texts/` | הטקסט כפי שהורד מבן-יהודה (נחלת הכלל בלבד) |
| `texts_clean/` | אחרי ניקוי: בלי שם המחבר בראש ובלי הערות שוליים |
| `texts_clean_nonikud/` | אותו טקסט נקי, בלי ניקוד |
| `texts_notes/` | הערות השוליים שהוסרו |
