# קורפוס ספרותי עברי — גרסה 3.1.0

**לצפייה בממשק:** https://adichouni.github.io/BenYehuda-literary-corpus/

שירים וסיפורים קצרים בעברית, לפי **עשור הלידה של המחבר** (1880 ואילך). כל עשור הוא תא נפרד.
בכל ז'אנר ועשור יש חמישה סטים, ובכל סט כל מחבר מופיע פעם אחת (עד 50 מחברים לסט). כשלמחבר
יש מספיק יצירות, בכל סט מופיעה יצירה אחרת שלו. סט 0 הוא הסט הראשי.

**מקורות:** [פרויקט בן-יהודה](https://benyehuda.org) (ב), הוצאת פרדס, ברשותה (פ),
והמהדורה המקוונת של [גרנטה](https://www.grantahebrew.com) (ג). סיפור קצר: עד 3,500 מילה.

"שירים" ו"סיפורים" = יצירות שונות בכל הסטים יחד. עשורי 1990 ו-2000 עדיין דלים.
פירוט לכל שנת לידה: `counts_by_year.csv`. פירוט לכל מחבר: `authors.csv`.

**שנות לידה:** ליצירות בן-יהודה, מרשומת המחבר בבן-יהודה. לפרדס ולגרנטה, מוויקינתונים, מגב הספר
או מהביוגרפיה בגרנטה. 27 מחברים מסומנים `birth_status = to_check`: שנת הלידה שלהם עוד לא אומתה
ידנית. הרשימה ב-`authors_to_check.csv`.

**טקסטים וזכויות:** הטקסט המלא מופיע כאן רק ליצירות שבנחלת הכלל (422 מתוך 2375). לשאר היצירות
מופיעים רק פרטי היצירה: ליצירות בן-יהודה שברשות בעלי הזכויות וליצירות גרנטה, עם קישור לקריאה במקור;
ליצירות פרדס, מחבר, ספר וכותרת בלבד. הקורפוס המלא, לשימוש מחקרי, נשמר אצל צוות המחקר.

| קובץ / תיקייה | מה יש בו |
|---|---|
| `sets.csv` | שורה לכל יצירה בכל סט: סט, ז'אנר, עשור, מחבר, שנת לידה, סטטוס שנת הלידה, מקור, קישור |
| `selection.csv` | שורה לכל יצירה שנמצאת בסט כלשהו, עם הסטים שלה ודגלי הניקוי. `in_core` מסמן את סט 0 |
| `authors.csv` | שורה לכל מחבר: שנת לידה, סטטוס, מקורות, מספר שירים וסיפורים (בכל הסטים ובסט 0) |
| `authors_to_check.csv` | המחברים ששנת הלידה שלהם עוד לא אומתה |
| `counts_by_year.csv`, `counts_by_decade.csv` | מספר שירים, סיפורים, משוררים וכותבי פרוזה לכל שנת לידה / עשור |
| `texts/` | הטקסט כפי שהורד מבן-יהודה (נחלת הכלל בלבד) |
| `texts_clean/` | אחרי ניקוי: בלי שם המחבר בראש ובלי הערות שוליים |
| `texts_clean_nonikud/` | אותו טקסט נקי, בלי ניקוד |
| `texts_notes/` | הערות השוליים שהוסרו |

`corpus_hash.txt` = sha256 של `sets.csv`.
